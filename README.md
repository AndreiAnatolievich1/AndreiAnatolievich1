## Обо мне

- Работаю дежурным инженером ЦУС: мониторинг сетей в **Zabbix/NMS**, диагностика каналов связи, обработка инцидентов и взаимодействие с абонентами.
- Высшее образование — **«Сети связи и системы коммутации»**, Российский университет транспорта.
- Собираю учебные стенды, документирую конфигурации и отрабатываю поиск неисправностей.
- Развиваю сетевую автоматизацию: **Python, Netmiko, Git**.
